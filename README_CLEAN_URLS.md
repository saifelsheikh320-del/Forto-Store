### المبدأ الأساسي:
1. **الروابط الداخلية**: كل الروابط في الكود تستخدم الصيغة النظيفة (بدون .html)
2. **ملف 404.html**: يعمل كمعالج للروابط النظيفة
3. **التوجيه التلقائي**: عند زيارة `/products`، يتم التوجيه إلى `products.html`

### مثال عملي:
```
المستخدم يزور: /products
↓
GitHub Pages لا يجد ملف اسمه "products"
↓
يعرض 404.html
↓
السكريبت في 404.html يكتشف أن "products" صفحة صحيحة
↓
يتم التوجيه إلى products.html
↓
المستخدم يرى الصفحة والرابط يبقى /products
```
